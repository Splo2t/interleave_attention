# Main benchmark results

Curated view for the paper's main benchmark evaluations, checkpoint sweeps, result dashboards, and selected CPT checkpoint links.

Paper main benchmark set:

- Korean: KMMLU, KoBEST, CLIcK, CSATQA
- English: MMLU, ARC-Easy, ARC-Challenge, HellaSwag, OpenBookQA
- Context-conditioned average: KoBEST, ARC-Challenge, HellaSwag

The model checkpoints under `model_checkpoints/` are local symlinks to the selected best-AVG CPT settings.
